문어 뱀서라이크 — Unity Relay(인터넷 Join Code) 설정

서로 다른 집 인터넷에서도 됩니다.
방장이 만든 참가 코드를 상대가 입력하면, Unity Relay 서버가 가운데서 연결을 중계합니다.
상대 집의 공인 IP나 공유기 포트 설정은 필요 없습니다. 다만 양쪽 모두 인터넷이 되어야 합니다.

==================================================
1. Unity 버전
==================================================
Unity 6000.5.7f1 로 이 프로젝트를 엽니다.
처음 열면 Packages 를 받아오고 컴파일합니다. 인터넷이 필요합니다.

==================================================
2. Unity 계정으로 에디터 로그인
==================================================
Unity Hub 또는 에디터 오른쪽 위 계정 아이콘에서 Unity ID로 로그인합니다.

==================================================
3. 이 게임을 Unity Cloud 프로젝트에 연결
==================================================
1) 에디터 메뉴 Edit > Project Settings > Services
2) Use the Unity Cloud Dashboard 또는 Project 연결
3) 새 프로젝트를 만들거나 기존 프로젝트 선택
   예 이름: OctopusSurvivors
4) Organization 을 고르고 Link / Bind

같은 빌드를 쓰는 두 PC는 같은 Unity 프로젝트 ID를 써야 합니다.
프로젝트 설정이 들어 있는 이 소스 ZIP을 상대에게 그대로 주면 ID가 같이 갑니다.
상대 PC도 Unity 계정 로그인은 해야 합니다.

==================================================
4. Dashboard 에서 서비스 켜기
==================================================
브라우저에서 https://cloud.unity.com 접속

1) 방금 연결한 프로젝트 선택
2) Multiplayer > Relay
   - Relay 사용을 켭니다 (Enable)
3) Player Authentication (또는 Identity)
   - Authentication 사용을 켭니다
   - Anonymous Sign-in (익명 로그인) 을 허용합니다
     플레이어가 Unity 계정 비밀번호를 게임 안에서 칠 필요는 없습니다.

무료 개발용 한도로 2인 테스트는 충분합니다.

==================================================
5. 에디터에서 한 번 확인
==================================================
Play 를 누른 뒤 로비에서
  [인터넷] 방 만들기
를 누릅니다.

성공하면 참가 코드(예: X7K2P9)가 대기실에 크게 나옵니다.
실패하면 노란 글씨로 이유가 나옵니다. 대부분 3~4번을 안 한 경우입니다.

==================================================
6. 다른 집과 플레이
==================================================
방장
  1) 게임 실행
  2) [인터넷] 방 만들기
  3) 참가 코드를 카톡/문자로 보냄

참가자
  1) 같은 빌드 실행 (서로 다른 버전이면 안 됩니다)
  2) 코드 입력
  3) [인터넷] 참가

같은 Wi-Fi가 아니어도 됩니다. 포트 7777 을 열어줄 필요도 없습니다.

==================================================
7. 기존 LAN(IP) 접속은 그대로
==================================================
학원/같은 공유기 테스트는 아래를 쓰세요.
  Host 시작 (LAN 테스트)
  상대 IP 입력 후 Join (LAN 테스트)

인터넷 방이 안 될 때 원인 가리기에 유용합니다.

==================================================
8. 컴파일 오류 확인 방법
==================================================
A. Unity 에디터
  - Console 창 (Ctrl+Shift+C)
  - 빨간 error 가 없으면 스크립트 컴파일은 된 것입니다.
  - 프로젝트 열 때 아래가 보이면 패키지가 빠진 것입니다.
    error CS0246: 'RelayService' could not be found
    → Window > Package Manager 에서 Multiplayer 패키지가 설치됐는지 확인

B. 에디터 메뉴
  - 문어 > 조합표 검증  (기존 요소 테스트, 네트와 무관)

C. Windows 빌드
  - 문어 > Windows 빌드
  - 실패하면 빌드 로그에 컴파일 오류가 찍힙니다.

두 PC 모두 이 소스로 다시 빌드해야 인터넷 참가가 됩니다.
