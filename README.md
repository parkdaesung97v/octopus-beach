# 문어지지마 (OctopusBeach)

두 사람이 함께 살아남는 Unity 2D 협동 뱀서라이크 게임입니다.
바다를 어지럽히는 거대한 문어 괴물을 두 꼬마 문어가 진주를 모아 다시 봉인합니다.

- 팀: 이승규, 박대성 (2인)
- 상태: 개발 중 (2026.10 기준)
- 엔진: Unity 6000.5.7f1

## 게임 소개

공격은 자동으로 나가고, 플레이어는 움직이며 진주를 모아 스테이지를 깹니다. 혼자 하는 뱀서라이크와 달리 두 사람의 협동이 규칙으로 들어가 있습니다.

- 한 명이 쓰러지면 다른 한 명이 파란 원 안에 3초간 서 있어야 살릴 수 있고, 둘 다 쓰러지면 게임이 끝납니다.
- 스테이지의 진주는 둘이 함께 중앙에 납품해야 채워집니다.
- 속성 4개(불, 물, 풀, 전기)가 자동으로 돌아가며 공격하고, 두 속성을 합치면 새 공격 6가지가 나옵니다.
- 스테이지를 깰 때마다 카드 3장 중 하나를 고릅니다.
- 5스테이지 보스를 잡으면 나오는 특수 요소(우주, 음양, 차원 균열 등)로 새로운 능력을 씁니다.

## 실행 방법

1. Unity Hub에서 `Source/문어_유한맵` 폴더를 프로젝트로 엽니다. (Unity 6000.5.7f1)
2. `Assets/Scenes`의 `SampleScene`을 열고 실행합니다.

## 온라인 협동 구성

플레이어 A가 방장이 되어 게임 계산을 맡고, Unity Relay는 두 사람 사이의 데이터만 중계합니다. 플레이어 B는 입력을 보내고 결과를 받습니다. 처음에는 같은 네트워크에서만 접속되는 포트 방식으로 만들었고, 다른 네트워크에서도 접속할 수 있도록 Relay로 바꾸었습니다. Relay를 처음 설정하는 방법은 [docs/Relay설정방법.txt](docs/Relay설정방법.txt)에 있습니다.

## 현재 상태와 앞으로

- 구현 완료: 속성 4개와 합성 6가지, 카드 선택, 5스테이지 보스 전투, 2인 협동과 부활
- 진행 중: Relay 온라인 협동. 접속은 동작하며, 방장이 아닌 접속자 쪽 반응이 느린 경우가 있어 원인을 확인 중입니다. 아직 해결하지 못했습니다.
- 예정: 다음 스테이지와 보스 추가, 전투 밸런스와 이펙트 개선

## 만든 방식

기획, 규칙 설계, 플레이 테스트와 오류 검증은 팀이 직접 했습니다. Unity C# 코드 구현과 에셋 제작은 AI 도구의 도움을 받았습니다.
